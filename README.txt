영광여중 플랫폼 체험관 — 웹 공간에 올리는 방법

1. 이 폴더의 HTML 파일(index.html + 플랫폼 12개 + kit.html)과 kit 폴더를 같은 구조 그대로 올립니다.
2. 시작 주소는 index.html 입니다.
3. 플랫폼별 바로가기: 주소 끝에 #go-hyrox, #go-poem 처럼 붙입니다.
   (studypass, onmusil, poem, escape, braille, hyrox, datalab, science, suno, smile, island, malhae)
4. 모든 학생·교사 이름과 기록은 체험용 가상 데이터입니다.
5. kit.html 은 따라 만들기 키트(만드는 방법 안내)이고, kit/planner, kit/compare 에
   Apps Script 예시 템플릿(Code.gs, Index.html)이 있습니다. Index.html 을 그냥 열면 저장되지 않는 미리보기로 동작합니다.
